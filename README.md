# Whispers Of The North

Projeto base do mod `wotn`, configurado com NeoForge para Minecraft `26.1`.

## Comandos úteis

- `./gradlew runClient` ou `gradlew.bat runClient`
- `./gradlew runServer` ou `gradlew.bat runServer`
- `./gradlew build` ou `gradlew.bat build`

## Estrutura

- Código Java em `src/main/java/com/somake/wotn`
- Metadados do mod em `src/main/templates/META-INF/neoforge.mods.toml`
- Recursos em `src/main/resources`
